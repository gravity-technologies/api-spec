!!! info "[ApiECNFromBrokerRequest](/../../schemas/api_ecn_from_broker_request)"
    Confirms size for an ECN order, in response to a last-look request on the `v1.ecn_to_broker` stream.<br>Only applicable to SFP (`kind = STABLE_PERP`) instruments; only qualified market makers can hold ECN orders.<br><br>The target order is identified by `order_id` or `client_order_id`. At least one must be provided;<br>if both are provided they must refer to the same order, and `instrument` must match that order.<br><br>`cumulative_confirmed_size` is an absolute running total for the order and must be a multiple of the<br>instrument's minimum size. Its value relative to the request's `cumulative_request_size` decides the outcome:<br>- **Full confirm** — equal to the requested size: the held matches are executed, and the order's remaining size stays live on the book.<br>- **Partial confirm** — between the previous confirmed value and the requested size: matches are executed up to the confirmed size, and the order's unconfirmed remainder is cancelled (terminal).<br>- **Decline** — re-send the previous confirmed value, or `0` if nothing was confirmed yet: no new size executes.<br>- **Underflow** — below the previous confirmed value: the order is cancelled (`ecnOrderSizeUnderflow`).<br>- **Overflow** — above the requested size: the order is cancelled (`ecnOrderSizeOverflow`).<br><br>`seq_no` echoes the `v1.ecn_to_broker` request being answered:<br>- A response at the latest `seq_no` covers all earlier outstanding requests.<br>- Retrying an already-processed `seq_no` is ignored, so duplicate sends of the same response are safe.<br>  This does not extend to lowering the total: a smaller `cumulative_confirmed_size` against the<br>  still-outstanding `seq_no` is rejected as an underflow, not treated as a retry.<br>- A value ahead of the latest published sequence number is rejected.<br><br>Respond before the request's `expiry_time` (1 second) — an unanswered request cancels the whole order (`ecnOrderExpired`).<br>

    |Name<br>`Lite`|Type|Required<br>`Default`| Description |
    |-|-|-|-|
    |sub_account_id<br>`sa` |string|True|The sub account ID that owns the ECN order being confirmed. Must match the sub account of the referenced order|
    |order_id<br>`oi` |string|True|A unique identifier for the order, generated within the GRVT backend. Required unless `client_order_id` is provided|
    |client_order_id<br>`co` |string|True|The client-specified identifier of the ECN order within the sub account. Required unless `order_id` is provided|
    |asset<br>`a` |string|True|The instrument of the ECN order. Must match the instrument of the referenced order|
    |seq_no<br>`sn` |string|True|The `seq_no` of the `v1.ecn_to_broker` message this confirmation responds to. A value ahead of the latest sequence number published for this order is rejected|
    |cumulative_confirmed_size<br>`cc` |string|True|The total size the broker has confirmed for this ECN order since inception. Must be a multiple of the instrument's minimum size increment and should not exceed the cumulative requested size|
